# Security Policy

## Scope

This policy covers the ZapTerm application binary and its source code. It does not cover the network
devices, servers, or infrastructure that users connect to via ZapTerm.

## Reporting a vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Send a description to: **security@zapterm.dev** (TBD — will be set up before public release).

Include:
- What you found and what impact it could have.
- Steps to reproduce.
- Any suggested fix, if you have one.

We will acknowledge receipt within 72 hours and aim to release a patch within 14 days for critical
issues.

## Bug bounty

There is no bug bounty programme at this time. ZapTerm is a volunteer-maintained open-source project.

## Supported versions

Until version 1.0.0 is released, only the latest commit on `main` is supported.
