Windows

Windows installer

Silent installation and exit codes, for administrators and deployment tools.

ZapTerm for Windows comes as two installers, built from the same release:

  • EXE — ZapTerm_<version>_x64-setup.exe, an NSIS installer.
  • MSI — ZapTerm_<version>_x64_en-US.msi, a Windows Installer package.

Both install the same 64-bit (x64) application and need the Microsoft Edge WebView2 Runtime, which Windows 11 and updated Windows 10 already include.

Silent installation

  • EXE: ZapTerm_<version>_x64-setup.exe /S (capital S).
  • MSI: msiexec /i ZapTerm_<version>_x64_en-US.msi /qn

Exit codes of the EXE installer

These are the standard exit codes of NSIS installers:

  • 0 — Installation completed successfully.
  • 1 — Installation cancelled by the user.
  • 2 — Installation aborted by the installer (an error occurred).

The MSI package returns the standard Windows Installer exit codes (for example 0 for success and 1602 when the user cancels), documented by Microsoft for msiexec.

Help

If an installation fails, open an issue on GitHub with the exit code and your Windows version.
