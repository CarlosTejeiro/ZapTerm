Privacy

Privacy policy

Last updated: 22 November 2026 (version 1.7.16)

ZapTerm is a free, open-source terminal application for network engineers, developed by Carlos Tejeiro and published at github.com/CarlosTejeiro/ZapTerm. This policy covers the ZapTerm application and this website.

The short version

The ZapTerm application does not collect, transmit or sell any personal data. It has no user accounts, no telemetry, no analytics, no advertising and no crash reporting. Everything you enter stays on your own device.

The application

Data it stores, on your device only

  • The sessions you save: names, host names or addresses, ports, user names, folders, notes and settings.
  • Passwords and key passphrases you choose to save. They are encrypted inside ZapTerm's data folder under a key that only your master password opens, never kept in clear text. If you choose "Remember on this computer", that one key is kept in your operating system's keyring so ZapTerm opens without asking.
  • Your macros, command lists, highlight rules, appearance settings and trusted host keys.
  • The commands you recently ran, to offer them again.
  • Session logs, when you record a session.

None of this is sent to the developer or to any third party. You can delete it at any time by removing the entries in the app or by deleting ZapTerm's data folder.

Network connections it makes

  • ZapTerm connects only to the devices and servers you tell it to connect to (SSH, Telnet, serial, SFTP, port forwards). The content of those sessions goes between your device and that host, and nowhere else.
  • It does not contact any server of the developer and does not check for updates by itself.
  • When you choose Help → Check for updates, it asks GitHub's public API (api.github.com) for the list of ZapTerm releases and, only if you click Download, downloads the installer from GitHub. These requests carry no account, identifier or data of yours; like any web request, GitHub sees your IP address, and GitHub's own privacy statement applies to them.

Optional backup and sync

If you create an encrypted backup or turn on the sync folder, ZapTerm writes one file, encrypted with a passphrase only you know, to a location you choose. If that location is synchronised by a cloud service you use, that service's own privacy policy applies to the file; it only ever holds the encrypted version.

Scripts

Python scripts and notebooks that you run from ZapTerm are your own code and run on your device. What they do with the data they read is under your control.

This website

  • The site uses no cookies, no analytics and no advertising.
  • It is hosted on GitHub Pages. As with any website, the host receives technical information such as your IP address when you load a page; see GitHub's privacy statement.
  • The download buttons ask GitHub's public API for the latest release, from your browser, to link to the right file.
  • Contact form. If you write through the form, the name, email address and message you enter are delivered to the developer by Web3Forms, a form-delivery service (their privacy policy). They are used only to read and answer your message and are not shared or used for anything else.
  • Donations are handled by PayPal on PayPal's own site; ZapTerm receives no payment details.
  • Suggestions and bug reports are public GitHub issues, subject to GitHub's terms.

Children

ZapTerm is a professional tool and is not directed at children. It collects no data from anyone.

Your rights

Because the application holds no personal data about you outside your own device, there is nothing for the developer to provide, correct or erase. If you wrote through the contact form and want that message deleted, ask through the same contact form.

Changes to this policy

If ZapTerm ever changes how it handles data, this page will be updated before the change is released, and the date at the top will change. Its history is public in the project's repository.

Contact

Questions about privacy: use the contact form or open an issue on GitHub.
